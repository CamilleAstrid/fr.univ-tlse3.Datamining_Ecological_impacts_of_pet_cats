# Jeux de données

Ce dossier contient les fichiers de données de test, afin d'éprouver le modèle.
Ce jeu de données a été récolté à l'aide des informations récoltées par les propriétaires de chats vivant en France.

## Sources
Nous avons demandé à des propriétaires de chats de nous remplir une fiche afin de collecter toutes les informations nécessaires à l'analyse.
De même, leur accord à été formulé par écrit et signé par les propriétaires et l'équipe de recherche.

## Description
Il s'agit de chats vivant dans le sud ouest de la France.
De nombreuses caractéristiques des chats étudiés y sont rencensées telles que l'âge, le sexe, les habitudes de chasse, etc.
